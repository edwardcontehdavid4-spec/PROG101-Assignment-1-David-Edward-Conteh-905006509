## Project Description

The Community Waste Management System (CWMS) is a beginner programming project designed to help record and manage waste collection requests in Jui, Sierra Leone.

The system allows users to enter waste locations, waste types, and request dates. Each request is assigned a reference number and given a status of Pending or Completed.

The project demonstrates basic programming concepts, including input, output, decision-making, procedures, and algorithms.

## Project Purpose

The purpose of this project is to demonstrate how programming logic can help organize community waste collection requests.

This system is a simple academic project. It does not physically collect waste or guarantee collection services.
